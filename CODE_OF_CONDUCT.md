# Código de conduta

Contribuições, discussões e revisões devem ser técnicas, cordiais e respeitosas. Não são aceitos ataques pessoais, discriminação, assédio, exposição de informações privadas ou incentivo a executar comandos perigosos sem explicar seus efeitos.

Se houver conflito, use os recursos de moderação do GitHub e procure o mantenedor de forma privada. Relatos técnicos de segurança devem seguir [SECURITY.md](SECURITY.md) em vez de issues públicas com detalhes exploráveis.
